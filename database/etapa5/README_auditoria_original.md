## Alcance de pruebas y pendientes
No se ejecutaron scripts DDL ni pruebas de escritura en Supabase. El contenedor PostgreSQL de pruebas debe ejecutarse en tu PC; no está disponible Docker/psql en el entorno de creación. Las pruebas locales prueban restricciones SQL, no sustituyen la prueba de integración JDBC ni la concurrencia compra/cancelación en PostgreSQL. Esas últimas se validarán en una instancia descartable con Spring Boot. Pendiente: zona horaria uniforme America/Lima en servidor y cliente; protección de cambios de sala/asiento por SQL directo; credencial JDBC de privilegios mínimos. El DDL de exclusión protege altas/ediciones simultáneas de funciones incluso si pasan el precheck Java. Revisar que HTTP 409 se devuelve ante SQLSTATE 23P01 (Spring tiene handler de integridad, falta prueba con PostgreSQL). No es necesario cambiar Java para usar la restricción.
